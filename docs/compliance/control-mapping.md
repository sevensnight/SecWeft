# Compliance Control Mapping

Control mapping is not certification.

P14 exports evidence mappings for:

- ISO/IEC 27001
- SOC 2 Trust Services Criteria
- NIST Cybersecurity Framework
- NIST SSDF
- OWASP ASVS
- OWASP SAMM
- SLSA
- CIS Kubernetes Benchmark

Each mapping includes control id, implementation notes, evidence references, owner, test, status, gap, exception, review timestamp, and `certification_claim=false`.

External certification, attestation, and operating-effectiveness sampling remain customer/auditor activities.
