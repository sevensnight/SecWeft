# SecWeft v2.14.1

Release date: 2026-07-28

SecWeft v2.14.1 is a post-release dependency maintenance release for the v2.14 production-ready line. It keeps the P14 product/runtime target identifier `2.14.0-p14` unchanged and records `v2.14.1` as the external maintenance release tag.

## Highlights

- React and React-DOM are aligned at `19.2.8`.
- React runtime alignment is now enforced by a dedicated validation script, unit tests, and CI steps.
- Dependabot grouping now isolates React ecosystem updates and excludes Monaco Editor and Playwright from broad workspace minor/patch updates.
- P0 release validation now supports clean detached Git worktrees.
